# 🥚 Huevos de Oro — Site Oficial

Site institucional da **Huevos de Oro — Taberna Española**, localizada em Pinheiros, São Paulo.

---

## 📋 Sobre o projeto

Site estático desenvolvido em **HTML, CSS e JavaScript puro**, sem dependências de frameworks — fácil de hospedar em qualquer plataforma (GitHub Pages, Netlify, Vercel, etc.).

### Seções

| Seção | Descrição |
|---|---|
| **Hero** | Banner principal com chamada para reservas |
| **¡Bienvenidos!** | Apresentação do restaurante com galeria de fotos |
| **Cardápio** | Call-to-action para o cardápio |
| **O Restaurante** | Endereço, horários e mapa integrado |
| **Espaços** | Entreposto e Salão para eventos privativos |
| **Reservas** | Links diretos para WhatsApp e e-mail |
| **Rodapé** | Contato, redes sociais e horários |

## 🖼️ Como adicionar as imagens

Adicione as fotos do restaurante na pasta `assets/images/` com os nomes listados acima. Recomendações:

- **hero-bg.jpg** — foto horizontal/paisagem de um prato ou ambiente. Tamanho ideal: 1920×1080px.
- **restaurante-1.jpg** — foto vertical do ambiente interno. Ideal: 800×1200px.
- **tapas-1.jpg / tapas-2.jpg** — fotos dos pratos. Ideal: 800×600px.
- **espaco-entreposto.jpg / espaco-salao.jpg** — fotos dos espaços. Ideal: 1200×800px.

> 💡 Use fotos do Instagram [@huevosdeorobar](https://www.instagram.com/huevosdeorobar/) para manter consistência visual com a marca.

---

## 🚀 Como publicar no GitHub Pages

1. Faça o upload de todos os arquivos para um repositório no GitHub
2. Acesse **Settings → Pages**
3. Em **Source**, selecione `main` branch e pasta `/ (root)`
4. Clique em **Save** — o site estará disponível em `https://seu-usuario.github.io/nome-do-repositorio/`
